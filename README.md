This is a CRM for the Metavida project https://www.metavida.life/mision/

The frontend must be done in sveltekit, following the structure and components of the Genix project, a public page and then a admin section.

you need a credentials.json file, must be in the gitignore where the cloudflare credentials must live

The backend must be a golang backend, following the same pattern as the genix project.

Do a git clone of the genix project and start installing and setting up this repo. The genix project is already here: /run/media/ivanjoz/projects/genix
